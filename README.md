# AgriFlow

Prototipe aplikasi perencanaan pembelian sekam padi untuk pembeli energi. Dibuat untuk Pertamuda Seed and Scale 2026.

Buka `index.html` di browser, atau kunjungi versi daring di https://moomtazz.github.io/AgriFlow/

Semua nama pemasok, harga, dan riwayat pengiriman di prototipe ini adalah data contoh untuk demonstrasi.
